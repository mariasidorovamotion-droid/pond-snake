# pond-snake
Уютная браузерная змейка: серый уж плавает по пруду и собирает лягушек — каждая запрыгивает ему на спину и едет дальше. Плавные повороты, живая вода, музыка и звуки, свайпы и клавиатура. Играется на телефоне, компьютере и как Mini App в Telegram. Один HTML-файл без сервера и библиотек.
